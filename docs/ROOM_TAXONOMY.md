# THRESHOLD — Room Taxonomy

63 main-floor templates + 14 Underscript templates, mapped onto the brief's categories. `w:` = template weight, `min:` = earliest room.

## Safe / recovery
- `safe-bunker` (w5): stocked shelter, generator, bed — full heal radio. Lore beat.
- `safe-haven` corridor landings: entity-skip zones every ~20 main rooms (generator rule) + all `%20` under landings.

## Tutorial / introduction
- `lobby-entry` (min0): teaches doors + lamp + prompts; no entity eligibility.
- Early corridor templates carry the "doors numbered" conceit.

## Suspicion-building
- `gallery-portraits` (w4, min12): `hauntedPortrait` variants — eyes track the player.
- `gallery-observation` (w3): one-way glass framing + watcher figure.
- `motel-corr-doors-row`: repeated door rhythm — doors open on their own (ambient system).

## Exploration
- `records-stacks`, `records-cage-room`, `records-vault`, `u-narrow-stacks`: dense shelving, sockets, hide mix.
- `gallery-*` family (portraits/atrium/mezzanine/observation/banquet/cathedral/rotunda/vaulted/broken/lift-lobby): the visual-spectacle wing.

## Puzzle
- `milestone-index` (room 50): Index cipher — authored milestone.
- `milestone-lens-hall` (room 75): lens alignment set piece.
- `milestone-engine` (room 100): Engine — run finale.

## Locked-route
- Lock placement is generated by `locks` stream; locked doors read brass plates; keys spawn in validated sockets before the lock (sim-gated).

## Hidden-route
- `records-vault` + `u-*` dead-end loot rooms; the Underscript hatch chain itself is the hidden route (Resonance Key gated).

## Observation / anomaly
- `relic` statue system (relocates when unobserved), `mirrorFig` stranger-behind-shoulder, corner-watcher figure (14s cap, lamp-gaze removal) — run-spanning anomaly set, all seeded.

## Threat-warning
- Every entity cue has an audio + caption pair; `warningTime` field per entity is the literal warning budget.

## Chase
- `milestone-chase-1`, `milestone-chase-2`: authored lane chases; `sweep`/`reprise`/`returner` corridor runners are organic chase beats.

## Hiding
- Every template declares `hiding` spots (cabinet/underFurniture/losAlcove/vent) + `safeZones`; sim validates coverage per room.

## Narrative / lore
- `documents.ts` note/diary system; `records-*` + `u-office-*` are the lore-heavy biomes; `gallery-banquet` = "dinner interrupted" vignette.

## Resource / utility
- Economy: Imprints currency, sockets (loot/drawer), vending/mechanical props, `shop` node rooms on the route.

## Set piece
- `gallery-cathedral` (w2, min45) — mill showcase; `gallery-banquet`; `morgue-drawers`; `maint-fabshop`; `gallery-lift-lobby` (scissor gates).

## Transition
- Corridor family: `corr-straight`, `corr-wide` (portal), `corr-doors-row`, `maint-pipes`, `u-corridor`, `u-long-hall` — kept visually varied via archways, wall hardware, prop pools.

## Climax
- `milestone-engine` (room 100) — the Engine; Underscript `u-editor-term` final room — the Editor confrontation.

## Per-archetype spec (required fields)

Each archetype carries in `templates.ts`: gameplay purpose (comment), visual identity (`wall`/`floor`/`props`), audio identity (biome ambience), lighting (`darkChance`, fixture lists), variations (`rng`-branched props, weight), spawn rules (`minRoom`, `weight`, `tags`), enemy compatibility (sim + skip lists), pacing (`perf` budget field), anti-repetition (variant pools + seeded dressing).
